# Eight-in-One Filament Adapter

This project features a 3D-printable **8-in-1 filament adapter** designed to combine up to eight PTFE tubes from multiple filament spools into a single PTFE output tube. It helps organize filament routing and minimize clutter—perfect for multi-material or multi-color 3D printing setups.

## Features
- Supports up to **8 individual PTFE tube inputs**
- Merges seamlessly into **one clean PTFE output**
- **Compact**, lightweight, and **easy-to-print** STL design
- Ideal for **multi-filament printing systems** or setups with filament changers
- Keeps **spool storage areas tidy** and ensures efficient filament flow

## Setup
Use **PC4-M6 PTFE connectors**. The connector hole diameter is **4 mm**.  

- **Version 1 (WIP):** Designed without threads—connectors are hot-pressed into place.  
- **Version 2 (coming soon!):** Includes proper threading, removing the need for hot-pressing.
